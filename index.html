[ MISSION OVERVIEW ]

SYSTEM-3 is a 1U CubeSat developed by the Stony Brook University Nanosatellite Division. The primary payload is a miniaturized gamma-ray spectrometer using a CsI(Tl) scintillator crystal coupled with a Hamamatsu SiPM array for detecting cosmic radiation in Low Earth Orbit.

The satellite features a 6-layer PCB stack architecture, solar-powered EPS with MPPT charging, and a UHF amateur radio downlink broadcasting unencrypted public science telemetry through the global SatNOGS ground station network. All hardware designs, firmware, and documentation are fully open-source.
